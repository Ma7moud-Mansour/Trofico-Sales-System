# استبدال بيانات العرض

أمر صيانة يدوي؛ لا يعمل عند إقلاع التطبيق. ملف المصدر ونسخ القاعدة وبيانات الدخول تُحفظ داخل `.runtime` المستبعدة من Git. لا تضعها في مجلد عام أو في مستودع الكود.

1. جهز Python مع مكتبة `xlrd` لقراءة ملف XLS القديم، ثم استخرج الدفعة:

   `python backend/scripts/extract-real-data.py "تعديلات سيستم.xls" --output .runtime/source-data.json`

2. خذ نسخة احتياطية قبل المهاجرة، ثم طبق المهاجرات بواسطة `npm run db:migrate:deploy` ونشر إصدار التطبيق الذي يدعم `representativeId` ومنطقة العميل الاختيارية ووزن العبوة.
3. افحص الدفعة والقاعدة بدون تعديل:

   `node backend/scripts/import-real-data.mjs --source .runtime/source-data.json --env-file .env`

4. أضف `--apply` لتنفيذ الاستبدال. يستخدم الأمر `MIGRATION_DATABASE_URL` إن وجدت، وإلا `DATABASE_URL`. يلزم حساب مالك الصيانة، وأدوات PostgreSQL عبر `PG_BIN`، وشهادة القاعدة المعتمدة للاتصال البعيد. لا تمرر كلمة المرور كوسيطة shell.

ينشئ الأمر نسخة `pg_dump` ويتحقق من فهرسها قبل التغيير، وينفذ الاستبدال داخل معاملة مقفلة. يرفض وجود عملاء خارج دفعة العرض أو طلبات وحركات مخزون غير مرتبطة ببيانات العرض. اختبر استعادة النسخة الاحتياطية على قاعدة منفصلة قبل الصيانة. لا تستخدمه لحذف تاريخ تشغيل حقيقي.

تُنشأ أكواد عملاء `C-00001` وأكواد أصناف `P-0001` وأسماء دخول مندوبين `rep.001` بالتتابع. تبقى علاقة كل عميل بمندوبه، وتبقى منطقة العميل ومناطق المندوب غير محددة حتى يحددها مدير النظام. المندوب لا يرى عملاءه ولا يطلب لهم قبل تخصيص منطقة نشطة؛ العميل ذو المنطقة المحددة يخضع لنطاق المناطق المعتاد. تُحفظ أوزان العبوات منفصلة عن وحدة البيع «عبوة»، ولا تُستنتج أرصدة من الأوزان.

يحفظ الأمر حسابات القيادة وكلمات مرورها، ويزيل بادئة `demo.` من اسم دخول حساب القيادة القديم إن وجدت. كلمات مرور المندوبين عشوائية، ويلزم تغييرها عند أول دخول. ملف `representative-access.json` سري داخل مجلد نتيجة الاستيراد؛ يعرض الأمر مساره فقط. المطابقة على بصمة الملف تمنع إعادة الاستيراد أو إعادة تعيين كلمات المرور عند تكرار نفس الأمر.

بعد التنفيذ تحقق من عدد العملاء والأصناف والمندوبين، وطابق الأسماء والأوزان مع المصدر، وقارن المناطق قبل وبعد. سجل عملية الاستيراد يحمل بصمة المصدر. لا ترجع إلى إصدار أقدم لا يدعم العملاء بدون مناطق بعد استيراد هذه الدفعة.
